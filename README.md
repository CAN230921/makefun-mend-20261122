`mend` is a deterministic, zero-dependency Node 22 TypeScript CLI that applies AI-written code edits in four formats (unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON edits) with 3-tier fuzzy matching, indentation re-alignment, and atomic all-or-nothing writes according to `SPEC.md`.

## Run it

```sh
node main.ts [--format=auto|unified|search-replace|v4a|json] [--check] [--strict] [PATCH]
```
